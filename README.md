# Bump Arena

공으로 상대를 밀어내는 대전 게임입니다. 공을 굴리고 뛰어서 상대를 발판 밖으로 떨어뜨리고, 마지막까지 발판 위에 남은 사람이 그 라운드의 점수를 얻습니다. 목표 점수에 먼저 도달한 사람이 우승합니다.

혼자서 AI와 연습할 수 있고, 방을 만들어 최대 6명이 같이 할 수 있습니다. 화면은 원작인 Bonk.io처럼 단순한 도형으로만 그립니다.

## 실행 방법

Node.js 22 이상이 필요합니다.

| 명령 | 하는 일 |
| --- | --- |
| `npm install` | 필요한 패키지를 설치합니다. |
| `npm run dev` | 개발 서버를 띄웁니다. 이 상태에서는 통신이 없으므로 연습하기만 할 수 있습니다. |
| `npx vite --mode web` | 브라우저끼리 직접 연결하는 방식(P2P)으로 개발 서버를 띄웁니다. 브라우저 창 두 개를 나란히 놓고 한쪽에서 방을 만들고 다른 쪽에서 방 코드로 들어가면 같이 하기를 확인할 수 있습니다. 가려진 탭은 브라우저가 멈추고, 경기 중에 10초 동안 응답하지 않는 사람은 나간 것으로 처리하므로 한 창의 탭 두 개로는 확인할 수 없습니다. |
| `npm test` | 테스트를 한 번 실행합니다. |
| `npm run build` | claude.ai에 올릴 빌드를 `dist`에 만듭니다. `dist/assets`에는 JS 파일 하나와 CSS 파일 하나만 나옵니다. |
| `npm run build:web` | 공개 사이트(GitHub Pages)에 올릴 빌드를 `dist-web`에 만듭니다. P2P 연결에 쓰는 코드가 별도 파일로 함께 나옵니다. |

`main` 브랜치에 올리면 `.github/workflows/pages.yml`이 테스트를 실행한 뒤 `dist-web`을 GitHub Pages에 배포합니다.

## 조작

| 동작 | 키보드 | 마우스 | 터치 |
| --- | --- | --- | --- |
| 왼쪽, 오른쪽으로 이동 | ← → 또는 A, D | | 왼쪽 아래의 ← → 버튼 |
| 뛰기 | 스페이스, ↑ 또는 W | | 왼쪽 아래의 ↑ 버튼 |
| 아래로 힘 주기 | ↓ 또는 S | | 왼쪽 아래의 ↓ 버튼 |
| 무거워지기 | X 또는 Shift | 오른쪽 버튼 | 오른쪽 아래의 '무겁게' 버튼 |
| 특수 동작(갈고리, 화살) | Z | 왼쪽 버튼 | 오른쪽 아래의 큰 버튼 |
| 화살 겨누기 | 모으는 동안 ← → 또는 A, D로 방향 돌리기 | 마우스 움직이기 | 모으는 동안 ← → 버튼 |

키 배치는 원작인 Bonk.io를 따릅니다. 무거워지기는 모든 모드에서 쓰고, 특수 동작은 갈고리와 화살 모드에만 있습니다. 클래식에서는 Z와 왼쪽 버튼이 아무 일도 하지 않으며, 터치 화면에도 특수 동작 버튼이 나오지 않습니다.

무거워지기를 누르고 있는 동안 공이 무거워져서 가벼운 공을 밀어냅니다. 누르고 있으면 효과가 3초에 걸쳐 줄어 평소 무게가 되고, 떼면 3초에 걸쳐 돌아옵니다. 남은 효과만큼 공의 무거운 표시가 진하게 보입니다. 줄에 매달려 있거나 화살을 모으는 동안에는 무거워질 수 없습니다.

터치 버튼은 터치 화면에서 경기에 참가하고 있는 동안에만 보입니다. 키보드를 쓰는 화면에서는 경기 중에 왼쪽 아래에 조작 안내가 나오고, 경기가 시작되고 몇 초 뒤에 흐려집니다. 키는 자판의 위치로 읽으므로 한글 입력 상태에서도 그대로 동작합니다.

화살 모드에서는 Z나 왼쪽 버튼을 누르는 동안 힘이 모이고 떼면 화살이 나갑니다. 모으기 시작하면 마지막에 움직이던 쪽의 비스듬한 위를 겨누고, 모으는 동안 좌우 키로 그 방향을 돌립니다. 왼쪽 키는 시계 반대 방향, 오른쪽 키는 시계 방향입니다. 마우스를 움직이면 화살이 내 공에서 마우스가 있는 곳을 향하고, 그 방향이 공 옆에 옅은 선으로 보입니다. 달리다가 모으기 시작하면 누르고 있던 좌우 키는 방향을 돌리지 않고, 한 번 뗐다가 다시 누를 때부터 돌립니다. 겨누는 방향은 마지막으로 쓴 장치가 정합니다. 마우스를 3초 동안 움직이지 않으면 키보드로 겨누는 것으로 봅니다(왼쪽 버튼으로 모으는 중에는 예외입니다). Z로 모으는 동안 좌우 키를 새로 누르면 그때 겨누던 방향에서 이어서 키보드로 돌리고, 마우스를 움직이거나 누르면 다시 마우스로 겨눕니다. 그 밖의 좌우 키는 이동에만 쓰이므로 마우스 조준을 바꾸지 않습니다. 힘을 모으는 동안에는 좌우로 움직일 수 없고, 뛰기와 아래로 힘 주기는 그대로 됩니다.

갈고리 모드에서 Z로 줄을 걸면 위쪽에서 가장 가까운 발판에 걸립니다. 왼쪽 버튼으로 걸면 내 공에서 마우스 쪽으로 처음 만나는 발판에 걸리고, 그쪽으로 8m 안에 발판이 없으면 위쪽에서 가장 가까운 발판에 걸립니다.

메뉴의 버튼을 누르는 클릭과 경기 중이 아닐 때의 클릭은 조작으로 치지 않습니다.

## 모드

특수 동작이 모드마다 다릅니다. 방장이 대기실에서 모드를 고릅니다.

| 모드 | 특수 동작 |
| --- | --- |
| 클래식 | 없습니다. 무거워지기로 버티면서 상대를 밀어냅니다. |
| 갈고리 | 누르는 동안 발판에 줄을 걸어 매달립니다. 줄에 매달려 흔들리며 상대를 밀어냅니다. |
| 화살 | 길게 누르면 힘이 모이고, 놓으면 화살이 날아갑니다. 화살에 맞은 공은 탈락합니다. |

갈고리 모드에서는 공 둘레의 고리가 줄의 충전량을 보여 줍니다. 줄을 걸 때마다 충전량이 10분의 1씩 바로 줄고, 매달려 있는 동안에는 4초에 전부를 쓰는 빠르기로 줄어듭니다. 줄을 풀고 0.5초가 지나면 3초에 걸쳐 다시 찹니다. 충전량이 10분의 1보다 많지 않으면 줄을 걸 수 없습니다. 다 쓰면 줄이 풀리고 고리가 빨갛게 변하며, 2.5초 동안 줄을 쓸 수 없다가 0에서부터 다시 찹니다. 빨간 고리는 잠김이 풀릴 때까지 남은 시간만큼 줄어듭니다. 줄에 매달린 채 다른 공과 세게 부딪쳐도 줄이 풀리고 충전량이 모두 사라지며 똑같이 잠깁니다. 닿아 있거나 밀리는 것만으로는 풀리지 않습니다.

방장은 목표 점수(3점, 5점, 7점), 맵, AI 수, AI 수준(쉬움, 보통, 어려움)도 정합니다. AI 수준은 처음에 보통이며, 쉬움은 상대를 늦게 알아차리고 덜 세게 달려들고, 어려움은 더 빨리 반응하고 자리 끝의 상대를 더 적극적으로 밀어냅니다. 맵은 16개이며, 대기실에서 맵 모양을 그린 작은 그림을 보고 고릅니다. '무작위'를 고르면 라운드마다 직전과 다른 맵이 나옵니다.

일부 맵에는 발판 장치가 있습니다.

| 장치 | 설명 |
| --- | --- |
| 튕기는 발판 | 초록색 발판입니다. 닿은 공을 보통 발판보다 훨씬 높이 튕겨 냅니다. 구멍, 방방 맵에 있습니다. |
| 움직이는 발판 | 정해진 길을 일정한 시간마다 오갑니다. 카운트다운 동안에는 멈춰 있습니다. 나룻배, 승강기, 시소 맵에 있습니다. |

## 같이 하기가 동작하는 방식

모든 브라우저가 물리 세계 전체를 계산하되, 자기 공의 결과만 자기가 확정하여 다른 사람에게 알립니다. 그래서 조작이 즉시 반영되고, 방장이 나가도 경기가 끊기지 않습니다.

- 사람마다 자기 상태(공의 위치와 속도, 누르고 있는 입력, 생존 여부, 줄, 화살, 무거워지기의 남은 효과, 갈고리 충전량)를 60ms 간격으로 올리고, 모두가 그것을 받아 봅니다.
- 상대 공도 내 화면의 물리 세계에 실제 물체로 있습니다. 마지막으로 받은 입력을 계속 적용하다가, 새 상태가 오면 받은 위치 쪽으로 부드럽게 맞춥니다. 차이가 1m 이상이면 받은 위치로 바로 옮깁니다.
- 탈락은 탈락한 본인이 정합니다. 화살도 맞은 사람의 화면을 기준으로 판정합니다. 줄에 매달린 채 부딪쳐서 줄이 풀리는 것도 매달린 본인의 화면을 기준으로 정합니다.
- 방장은 AI의 움직임과 탈락, 라운드의 승자와 점수, 다음 단계로 넘어가는 시점, 다음 맵을 정합니다. 방장은 방에 가장 먼저 들어온 사람이며, 방장이 나가면 그다음으로 들어온 사람이 이어받습니다.
- 경기 중에 들어온 사람은 구경하다가 다음 라운드부터 참가합니다.
- 경기 중에 10초 동안 소식이 없는 사람은 나간 것으로 봅니다. 방에서 보이지 않게 된 참가자는 3초를 더 기다린 뒤에 탈락으로 처리합니다.
- 경기 중에 방장의 화면이 가려지면 다음 사람이 바로 방장을 이어받습니다.

연결 방식은 두 가지입니다. claude.ai 안에서 열면 claude.ai의 room 기능을 쓰고, 공개 사이트용 빌드에서는 PeerJS로 브라우저끼리 직접 연결합니다. 공개 사이트에서는 주고받는 값의 형식 버전(`src/net/wire.ts`의 `WIRE_VERSION`)이 다른 브라우저끼리 같은 방 코드를 써도 서로 다른 방이 되므로, 옛 버전을 열어 둔 사람은 새로 고친 뒤에 들어와야 합니다. 둘 다 쓸 수 없는 환경에서는 연습하기만 할 수 있습니다.

### 한계

- 충돌하는 순간의 결과가 화면마다 조금 다를 수 있습니다. 내 화면에서는 상대를 세게 밀었는데 상대 화면에서는 덜 밀린 것으로 계산되는 경우가 가끔 생깁니다.
- 쏜 사람의 화면에서는 화살이 맞은 것처럼 보였는데 상대가 탈락하지 않는 경우가 생길 수 있습니다.
- 통신 지연이 클수록 이 차이가 커집니다.
- 방 코드 말고는 방을 지키는 장치가 없으므로, 방 코드는 같이 할 사람에게만 알려 줍니다.
- 브라우저가 가려진 탭의 계산을 늦추므로, 탭을 0.5초 넘게 가렸다가 돌아오면 밀린 시간을 한꺼번에 계산하지 않고 현재 상태에서 이어 갑니다.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `src/main.ts` | 입력, 경기, 그리기, 메뉴, 소리를 연결하고 매 프레임을 진행합니다. |
| `src/multiplayer.ts` | 방과 대기실, 방장 선출, 상태 송수신을 맡습니다. 연습하기도 나만 있는 방으로 같은 경로를 씁니다. |
| `src/session.ts` | 한 경기를 실행합니다. 물리 세계, 경기 진행, AI, 받은 상태 맞추기를 묶습니다. |
| `src/physics/` | 공과 발판의 물리 세계(`world.ts`), 화살(`arrows.ts`), 도형 계산(`geometry.ts`)입니다. |
| `src/game/` | 대기실 규칙(`lobby.ts`), 맵(`maps.ts`), 모드와 수치(`modes.ts`), 경기 진행 단계(`round.ts`), AI(`bot.ts`), AI 수준별 조절값(`bot-skill.ts`)입니다. |
| `src/net/` | 연결 방식 고르기(`connect.ts`), 혼자 쓰는 방(`local-room.ts`), P2P 방(`p2p-room.ts`), 주고받는 값의 형식(`wire.ts`)입니다. |
| `src/render/` | 경기 화면 그리기(`scene.ts`), 물리 계산 사이를 이어 그리는 계산과 찌그러짐·짧은 멈춤(`pose.ts`), 탈락 조각·충돌 불꽃·화면 흔들림(`effects.ts`), 화면 밖 공의 표시(`edge.ts`), 조작 안내(`hints.ts`)입니다. |
| `src/ui/menus.ts` | 처음 화면, 대기실, 경기 중 버튼, 최종 결과 화면입니다. |
| `src/input.ts` | 키보드, 마우스, 터치 버튼 입력을 읽습니다. |
| `src/audio.ts`, `src/sounds/` | 효과음 재생과 효과음 파일입니다. |
| `src/storage.ts` | 이름과 색을 브라우저에 저장합니다. `bonk-arena.profile.v1` 키만 읽고 씁니다. |
| `tests/` | Vitest 테스트입니다. |
| `docs/superpowers/` | 설계 문서와 구현 계획입니다. |

## 소리 출처

효과음은 [Kenney](https://www.kenney.nl)의 무료 효과음 묶음 두 가지에서 가져왔습니다. 두 묶음 모두 Creative Commons Zero(CC0) 라이선스입니다.

| 묶음 | 사용한 소리 |
| --- | --- |
| [Impact Sounds](https://kenney.nl/assets/impact-sounds) | 충돌(`hit`), 탈락(`out`), 화살이 박히는 소리(`stick`), 뛰기(`jump`) |
| [Interface Sounds](https://kenney.nl/assets/interface-sounds) | 화살 발사(`shoot`), 줄 걸기(`rope`), 카운트다운(`tick`), 시작(`go`), 승리(`win`), 버튼(`click`) |

원본 ogg 파일을 mono 48kbps mp3로 변환하여 `src/sounds/`에 두었고, 빌드할 때 JS 파일 안에 함께 넣습니다.
